## 💭 Note to Future Me

When I built this project, I had only recently learned CSS Grid.

The original plan was supposed to be a small Grid practice project.

Somehow, that turned into me spending hours searching for the perfect Minecraft screenshots, finding shader footage, tweaking typography, adjusting spacing by single pixels, and treating a Minecraft fan page like I was designing the official game website.

Classic.

At this point, I’ve learned that every “quick project” somehow becomes a multi-hour obsession.

I also remember building this after finishing my Bocchi The Rock project and thinking:

“Okay, this one will be smaller.”

Yeah… sure.

Looking back, I hope this project reminds me that progress doesn’t happen overnight. A months ago I was learning to center a div. Now I’m building websites with video backgrounds, CSS Grid layouts, animations, Git, GitHub Pages deployments, and enough aesthetic obsession to spend 30 minutes deciding whether a heading should have 0.30em or 0.35em letter spacing.

I also hope Future Me remembers that this website was built during a time when I constantly worried about AI replacing developers.

If you’re reading this years later and you’re already working in tech, then congratulations.

The worrying was probably unnecessary.

And if somehow you’re running a successful startup, building software used by thousands of people, or driving a ridiculous sports car…

Remember that one day you were a 16-year-old kid in Minas Gerais making Minecraft fan pages on a weekend and thinking:

“Maybe this coding thing will work out.”

Keep building.

Keep learning.

And for the love of all things Minecraft…

go to sleep earlier than 3 AM before school.
